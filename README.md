# 담장 조별 루트 세팅 채점판

클라이밍장 이벤트용 채점 집계 페이지. 5개 조가 각 2문제씩 세팅한 10개 문제를
종이 평가지로 평가받고, 그 점수를 옮겨 담아 조별 평균과 1등 조를 즉시 뽑는다.

- **단일 파일**: `index.html` 하나가 전부. 빌드 도구도 백엔드도 없다.
- **점수**: 0.5 ~ 5.0, 0.5점 단위.
- **조 점수**: 그 조 2문제의 평균.
- **저장**: 브라우저 localStorage. 입력한 기기에만 남는다(아래 참고).

## 쓰는 법

1. `평가지 입력` — 종이 한 장을 보고 문제마다 점수를 친다.
   숫자를 이어 치면 다음 칸으로 자동으로 넘어간다(`4` 치고 `.5` 면 4.5, `4` 치고 `3` 이면 4점/3점).
   자기 조 문제처럼 빈 칸은 `↓` 로 건너뛴다. `Enter` 로 저장.
2. 잘못 넣은 장은 아래 `입력한 평가지` 에서 번호를 눌러 수정·삭제.
3. `결과` — 조 1등과 문제 1등이 카드로, 그 아래 조 순위 5줄과 문제 순위 10줄.
   `CSV 내보내기` 로 엑셀용 파일을 받는다.

## 데이터 보관 주의

입력 내용은 **그 브라우저에만** 저장된다. 여러 기기에서 나눠 입력하면 합산되지 않으니
한 기기에서 끝까지 입력하고, 끝나면 CSV를 받아 두는 것을 권한다.
(여러 명이 동시에 입력해야 하면 Supabase 같은 공용 저장소를 붙이면 된다.)

## 로컬 실행

```bash
python -m http.server 8899
# http://localhost:8899
```

`index.html` 을 브라우저로 바로 열어도 동작한다.

## 배포 (Vercel)

빌드 설정이 필요 없는 정적 사이트다.

1. 이 리포를 GitHub에 올린다.
2. vercel.com → Add New → Project → 이 리포 import.
3. Framework Preset `Other`, Build Command 비움, Output Directory `.` 로 두고 Deploy.

이후 `index.html` 을 고쳐 push 하면 자동으로 재배포된다.

## 조·문제 이름 바꾸기

`index.html` 의 `defaultConfig()` 안에서 조 이름과 문제 이름을 고친다.
`target` 은 전체 평가지 장수(기본 30)이고, 화면의 진행 카드에서도 바꿀 수 있다.
